Oura Drive Export

A personal integration that archives the owner's authorized Oura data in their Google Drive. A scheduled GitHub Actions workflow retains original API responses, creates deduplicated JSONL collections, and generates a daily CSV summary.

This is a private-use automation with public source code, not a service accepting accounts from the public. The website contains documentation only; it has no sign-in form, tracking scripts, credentials, or health records.

Google Drive access lets the exporter read the existing archive and write updated exports in the configured folder. Health records are processed temporarily on GitHub-hosted runners and retained in the owner's Drive. The exporter does not change file sharing permissions.
