Oura Drive Export

Privacy policy

Updated October 21, 2026. This policy describes the personal-use exporter in the linked source repository.

Data and purpose

The exporter reads the owner's authorized Oura records, including sleep, activity, readiness, heart and other wellness measurements, workouts, tags, and account/profile information available under the granted scopes. It reads existing export files and metadata in the configured Google Drive folder and writes raw responses, normalized records, summaries, and a manifest there. These operations support personal archiving and analysis.

Access, processing, and storage

The Google OAuth Drive scope can authorize access across the account's Drive; the exporter code limits its operations to the configured archive and referenced export files. Oura and Google issue the credentials. Credentials are stored in encrypted GitHub Actions environment Secrets. GitHub-hosted runners temporarily process the records; Google Drive stores the retained exports. The exporter does not publish health data in the public repository, logs, website, or workflow artifacts, and does not change Drive sharing permissions.

The exporter does not sell data, use it for advertising, or train AI models. An owner may separately authorize a health coach or another application to read their Drive exports; those services have their own data handling practices.

Retention and control

Historical exports remain until the owner removes them. Deleting a source record does not automatically remove archived copies. The owner can stop the GitHub Actions workflow, delete its Secrets, revoke the application in Oura or Google account settings, and remove the Drive archive and versions. Revocation stops future access but does not itself erase existing exports.

Website and contact

This documentation site has no application cookies, analytics scripts, or input forms. GitHub Pages may process ordinary hosting request information under GitHub's privacy statement. For non-sensitive project questions, use the repository issue tracker. Never post health data, credentials, or authorization URLs in public issues.
