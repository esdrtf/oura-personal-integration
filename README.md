# Personal Oura MCP

This is a private integration for its owner's personal use, not a public service. It uses the unofficial davidmosiah/oura-mcp software to read the owner's Oura account through Oura's API.

## Privacy Policy

The integration accesses only data authorized by the owner, which may include sleep, readiness, activity, heart rate, oxygen saturation, workouts, sessions, tags, and profile information. OAuth credentials and tokens are stored on the owner's computer and used to authenticate with Oura. Data requested through Codex is provided to OpenAI for processing and is subject to the owner's OpenAI account settings and applicable OpenAI policies. This integration does not sell data or intentionally publish health data. Local files and conversation history may retain information until the owner deletes it. Access can be revoked through Oura, and local credentials can be deleted. This integration is not offered to other users.

## Terms of Use

This integration is for the owner's personal informational use only. It is unofficial and is not endorsed by Oura. It provides no medical diagnosis or treatment and makes no guarantees about data completeness, availability, or accuracy. Oura's API agreement and the applicable terms of the connected services continue to apply. It is not a service offered to the public.
